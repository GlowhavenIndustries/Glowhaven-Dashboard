## Reporting a Vulnerability

We take the security of our self-hosted platform seriously. If you discover a security vulnerability or an architectural defense bypass, please use GitHub's native reporting system.

### How to report:
1. Navigate to the **Security** tab at the top of this repository.
2. In the left sidebar under "Reporting", click on **Advisories**.
3. Click the **Report a vulnerability** button to securely and privately submit your report.

Please do not open a public GitHub Issue for security bugs. Using this private reporting channel ensures we can securely collaborate on a fix and protect self-hosted enterprise environments before the vulnerability is made public. Thank you!
